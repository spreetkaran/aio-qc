The interface

Main window

AreaWhat it does
ToolbarLoad video (click; the arrow lists recent videos), output folder, save frame, ROI and tracking, in / out, bookmarks, markers, detections, batch, review gallery, Testing — and the output bar (format, quality, naming).
Video canvasThe picture, with ROI, detections and overlays. Wheel = step frames; Ctrl + wheel = zoom around the cursor; middle-drag (or drag when zoomed) = pan; double-click toggles fit ↔ 100 %.
SeekbarClick or drag to jump; hover for a thumbnail preview.
Timeline stripUnder the seekbar: sharpness bars (red = below your blur threshold), motion line, scene cuts, an optional model track, and the marker lane. Right-click for options.
Transport rowRewind / step / play / step / forward, the position display, step size, speed and zoom buttons (Fit and 100 % light up while active).
Docks (right)Marks (bookmarks, in / out), Markers (picked frames, snap, suggest, extract) and Search frames. Drag them anywhere; View ▸ Reset window layout restores the default.
Status barPixel under the cursor, ROI, sharpness of the current frame, decoder and playback information.

The position display

Shows the current time and frame. Click it to type a position — 1:23.5, 00:01:23:12, 1234f, 42%, +5s, -30f, in, out, end. Scroll on a unit (hours, minutes, seconds, frames) to nudge it, Shift for ×10; drag sideways to scrub. The format chip cycles Time · Timecode (SMPTE, drop-frame aware) · Frames · Seconds · Remaining.

Finding commands

  • Command palette — Ctrl+K: type any part of a command name and press Enter.
  • This guide — F1; shortcut reference — Ctrl+/; Help ▸ Customize keyboard shortcuts changes any of them, with conflict checking.
  • Get Started — Help ▸ Get Started replays the one-minute tour.
  • Tooltips — hover any control for a short explanation.

Appearance

  • Theme — the whole of AIO QC follows your system's light or dark setting.
  • Renderer — Settings ▸ Display ▸ Video renderer: GPU (OpenGL, recommended) or Software.
  • Animations — Settings ▸ General ▸ Animations: Full, Reduced (shorter, gentler) or Off. Animations run at your display's refresh rate and never faster.
