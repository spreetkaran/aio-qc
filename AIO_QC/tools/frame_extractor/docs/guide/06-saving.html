Saving frames

Ctrl+S saves the current frame (cropped to the ROI when one is set); Ctrl+Shift+S saves the full frame. Frames are always saved from the exact, full-resolution decoder — never from the scaled playback picture.

Format and quality

Choose on the toolbar's output bar or in Settings ▸ Output ▸ Format & file names (Ctrl+Shift+N), which also estimates the file size on the current frame. One quality value (0–100, default 95) is mapped to each format. The same settings are used by markers, batch extraction and the command line.

File names

A naming template is a path relative to the output folder, without extension. Tokens in braces are replaced; a / creates sub-folders; format specs work as in Python ({frame:06d}, {sec:.2f}). Characters that are not allowed in file names are replaced, so every template is safe on Windows.

When a file already exists

Overwrite it, keep both (adds _1, _2 …), or skip the frame — your choice in the naming dialog.

Note — a template without {frame}, {time}, {tc}, {sec}, {ms} or {counter} would give every frame the same name, so _{frame} is appended automatically.
