Command line

Everything heavy also runs without the window — on a server, in a script, or overnight:

aio-qc <command> [options]
CommandDoes
extractBatch extraction (same settings and presets as the batch queue)
probeDecoder, frame-rate, VFR and rotation information for videos
testsetBuild or extend a Testing test set of unique frames
evalScore weights on a test set / dataset / videos and write the HTML report
clipCut a clip (fast lossless, or --exact)

Examples

# one sharp frame per second, skip near-duplicates, 4 workers
aio-qc extract D:/videos -o D:/frames --mode sharpest --every 1s --dedup 2 -w 4

# test set from two videos and a folder, then compare two models
aio-qc testset testsets/gate --add cam1.mp4 cam2.mp4 frames/ --every 1s
aio-qc eval testsets/gate -m old.pt -m new.onnx --env yolo --report comparison

# cut 1:00 - 1:30 frame-exactly
aio-qc clip cam1.mp4 1:00 1:30 -o clip.mp4 --exact
