Models & pre-annotations

Settings ▸ Models holds one model configuration shared by the detection overlay, the timeline model track, marker pre-annotations, batch mining and Testing.

Model files

WeightsRun whereSetup
.onnxInside the app (ONNX Runtime, or OpenCV DNN)None
.pt, .engine, .torchscriptIn a Python environment with ultralytics + torch, through a small server process (the app itself never loads torch)Pick the environment — or let the dialog find one; with none available, one click builds a temporary environment (optionally reusing an existing PyTorch) that is removed on exit

Class names and the training image size come from the model file; GPU devices come from the environment. Test load and Test on current frame check a model before you rely on it; Export .pt → ONNX converts a .pt through ultralytics.

Options

  • Confidence / IoU — detection threshold and NMS overlap.
  • Uncertainty band — confidences in this range count as “uncertain” (timeline track, mining).
  • Image size — 0 = the size the model was trained at.
  • Device, half precision (FP16 on the GPU), SAHI sliced inference for small objects in large frames (needs sahi in the environment).

Where models are used

  • D — detections on the paused frame, one colour per model.
  • Tools ▸ Run models in timeline analysis — a model row on the timeline strip (purple = detections, amber = uncertain or disagreeing models); F jumps to flagged samples.
  • Markers and batch — pre-annotations (LabelMe / YOLO) and mining.
  • The Testing — measuring and comparing models.
