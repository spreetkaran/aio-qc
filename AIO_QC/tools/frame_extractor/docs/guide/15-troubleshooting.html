Troubleshooting

ProblemWhat to do
libmpv is not used / “mpv could not play the file”Open Settings ▸ Playback ▸ libmpv…: it shows why (not found, wrong architecture, undefined symbol = built for a newer system - use your distribution's package) and gets a working one (Get libmpv automatically). After a failed automatic download the app waits 3 days before trying again by itself; the button works any time. libmpv needs the GPU renderer.
The app closed while opening or playing a videoOn the next start it switches to safe settings (for example the software renderer instead of the GPU one), tells you what changed, and links to the crash report. Help ▸ Open log folder has the details.
“ffmpeg was not found”Install ffmpeg (or pip install imageio-ffmpeg) and set Settings ▸ Playback ▸ ffmpeg.
Playback drops framesTurn on the statistics overlay (Ctrl+Shift+I) to see the cause. Install libmpv, keep the GPU renderer, and run Playback ▸ Benchmark decoders.
Times look wrong on phone / screen recordingsThey are variable-frame-rate: install PyAV and use Decoder ▸ Auto or PyAV.
A .pt model will not loadSettings ▸ Models ▸ Python environment ▸ Check lists the versions and GPUs it sees; Find automatically looks through all environments; or install into a temporary environment.
Testing: “no class names in common”The dataset's class names differ from the model's. Fix data.yaml / classes.txt, or rename classes consistently.
Testing scores look too goodCheck that the ground truth is not unreviewed pre-labels from the same model (they are excluded by default).
Text search says it needs CLIPInstall open_clip_torch into the environment from Settings ▸ Models, or use the Built-in engine for “find similar”.
The interface feels busySettings ▸ General ▸ Animations ▸ Reduced or Off.

Reporting a problem

Include the log file (Help ▸ Open log folder), the Frame Extractor version (Help ▸ About) and, for video problems, the output of aio-qc probe <video>.
