Clips & annotated video

Export clip

File ▸ Export clip (Ctrl+Shift+X) cuts the in → out range (set with I and O).

ModeResult
FastNo re-encoding: original quality and instant. A clip can only begin on a keyframe, so it may start a little before your in point — the dialog shows exactly where.
ExactRe-encoded, starting and ending on the exact frames. Uses the GPU encoder when one works on this PC (NVENC, Quick Sync, AMF, VideoToolbox), else x264.

Export annotated video

File ▸ Export annotated video draws one to four models on the video — on one picture or side by side (two models left / right, three or four in a 2×2 grid) — with track IDs and a small information overlay. Predictions are cached and shared with Testing, so re-exports are fast.

Both exports run in the background, can be cancelled, and write to a temporary file that is renamed only when complete — a cancelled export never leaves a broken file behind.
