Settings & performance

The Settings window

Every preference is in one window: the gear at the right of the menu bar, File ▸ Settings… (Ctrl+,) or the command palette. Image QC and Data Studio have the same window with their own settings. Type in Search settings (Ctrl+F) to find one by name or by what it does; the sections on the left follow the page as you scroll. Changes apply at once. A setting that is not at its default shows ↺ to put it back; each section can be reset, and Export… / Import… save and load all settings as a file (for example to give a team the same set-up).

The menus keep what you do (open, play, mark, extract, export); what you set is here. Playback ▸ Benchmark decoders for this video stays in the Playback menu.

Performance tips

  • Install libmpv and keep the GPU renderer for the smoothest playback; install PyAV for fast timeline analysis.
  • Batch: leave workers on Auto — they adapt to your CPU, memory and current load. Lower Use of this PC to keep working while it runs.
  • Testing: a larger batch size is faster on a GPU; .onnx models with a dynamic batch axis run whole batches in one pass.
  • Every background task runs at reduced priority, and all helper processes stop with the app — even if it crashes.
