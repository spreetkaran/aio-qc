Search frames

Ctrl+F opens the Search frames panel. Click a result to jump there; right-click it to add an extraction marker or to find more like it.

Two ways to search

SearchHow
By descriptionType what you are looking for — white van, person on a bike, night — and press Enter. Words starting with - push results away: truck -night.
By exampleFind similar to this frame uses the current frame — or only the ROI with ROI only ticked.

Engines

  • CLIP understands what is in the picture and supports both kinds of search. It runs in the same Python environment as .pt models: install it there once with pip install open_clip_torch (or transformers); the weights download on first use, then everything works offline.
  • Built-in needs nothing and compares colour, layout and edges — good for finding the same scene or camera view.

Indexing

The first search of a video indexes it — one frame every N seconds (GPU-decoded in ffmpeg; very long videos are sampled more sparsely, at most about 6000 frames). Indexes are kept on disk, so later searches are instant, and an interrupted index continues where it stopped. Choose This video + other videos to search several videos at once.
